# Activity Manager v1 (Modul 3 - Laravel Basic)

Aplikasi manajemen kegiatan berbasis Laravel 13 yang menerapkan arsitektur *Separation of Concerns*, pemisahan *business rules*, validasi *Form Request*, serta *Clean Code*.

## Prasyarat Lingkungan
- PHP >= 8.3 (Teruji pada PHP 8.5.0)
- Composer >= 2.8
- Ekstensi SQLite aktif
